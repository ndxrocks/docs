## Code

```python tool_use.py
from kern.agent import Agent
from kern.models.aws import AwsBedrock
from kern.tools.hackernews import HackerNewsTools

agent = Agent(
    model=AwsBedrock(id="mistral.mistral-large-2402-v1:0"),
    tools=[HackerNewsTools()],
        markdown=True,
)
agent.print_response("Whats happening in France?", stream=True)
```
