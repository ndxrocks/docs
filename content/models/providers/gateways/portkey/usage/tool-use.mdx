## Code

```python cookbook/11_models/portkey/tool_use.py
from kern.agent import Agent
from kern.models.portkey import Portkey
from kern.tools.hackernews import HackerNewsTools

agent = Agent(
    model=Portkey(id="@first-integrati-707071/gpt-5-nano"),
    tools=[HackerNewsTools()],
    markdown=True,
)

# Print the response in the terminal
agent.print_response("What are the latest developments in AI gateways?")
```
