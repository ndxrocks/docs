## Code

```python cookbook/11_models/litellm/db.py
from kern.agent import Agent
from kern.models.litellm import LiteLLM
from kern.db.sqlite import SqliteDb
from kern.tools.hackernews import HackerNewsTools

# Setup the database
db = SqliteDb(
    db_file="tmp/data.db",
)

# Add storage to the Agent
agent = Agent(
    model=LiteLLM(id="gpt-5-mini"),
    db=db,
    tools=[HackerNewsTools()],
    add_history_to_context=True,
)

agent.print_response("How many people live in Canada?")
agent.print_response("What is their national anthem called?")
```
