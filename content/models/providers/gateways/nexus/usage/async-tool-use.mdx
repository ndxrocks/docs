## Code

```python cookbook/11_models/nexus/async_tool_use.py
"""
Async example using Nexus with tool calls
"""

import asyncio

from kern.agent import Agent
from kern.models.nexus import Nexus
from kern.tools.hackernews import HackerNewsTools

agent = Agent(
    model=Nexus(id="anthropic/claude-sonnet-4-20250514"),
    tools=[HackerNewsTools()],
    markdown=True,
)

asyncio.run(agent.aprint_response("Whats happening in France?"))

```
