## Code

```python cookbook/11_models/vllm/basic.py
from kern.agent import Agent
from kern.models.vllm import VLLM

agent = Agent(
    model=VLLM(id="Qwen/Qwen2.5-7B-Instruct", top_k=20, enable_thinking=False),
    markdown=True,
)

agent.print_response("Share a 2 sentence horror story")
```

## Usage

<Steps>
  <Snippet file="create-venv-step.mdx" />

  <Step title="Setup vLLM Server">
    Start a vLLM server locally:
    ```bash
    uv pip install vllm
    python -m vllm.entrypoints.openai.api_server \
      --model Qwen/Qwen2.5-7B-Instruct \
      --port 8000
    ```
  </Step>

  <Step title="Install dependencies">
    ```bash
    uv pip install -U openai kern-ai
    ```
  </Step>

  <Step title="Run Agent">
    ```bash
    python cookbook/11_models/vllm/basic.py
    ```
  </Step>
</Steps>
