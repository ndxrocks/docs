## Code

```python cookbook/11_models/anthropic/pdf_input_url.py
from kern.agent import Agent
from kern.media import File
from kern.models.anthropic import Claude

agent = Agent(
    model=Claude(id="claude-sonnet-4-20250514"),
    markdown=True,
)

agent.print_response(
    "Summarize the contents of the attached file.",
    files=[
        File(url="https://kern-public.s3.amazonaws.com/recipes/ThaiRecipes.pdf"),
    ],
)
```
