## Code

```python cookbook/11_models/google/gemini/pdf_input_url.py
from kern.agent import Agent
from kern.media import File
from kern.models.google import Gemini

agent = Agent(
    model=Gemini(id="gemini-2.0-flash-exp"),
    markdown=True,
)

agent.print_response(
    "Summarize the contents of the attached file.",
    files=[File(url="https://kern-public.s3.amazonaws.com/recipes/ThaiRecipes.pdf")],
)
```
