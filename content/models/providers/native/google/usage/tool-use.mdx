## Code

```python cookbook/11_models/google/gemini/tool_use.py
from kern.agent import Agent
from kern.models.google import Gemini
from kern.tools.hackernews import HackerNewsTools

agent = Agent(
    model=Gemini(id="gemini-2.0-flash-001"),
    tools=[HackerNewsTools()],
    markdown=True,
)
agent.print_response("Whats happening in France?")
```
