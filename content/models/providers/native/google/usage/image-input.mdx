## Code

```python cookbook/11_models/google/gemini/image_input.py
from kern.agent import Agent
from kern.media import Image
from kern.models.google import Gemini
from kern.tools.hackernews import HackerNewsTools

agent = Agent(
    model=Gemini(id="gemini-2.0-flash-exp"),
    tools=[HackerNewsTools()],
    markdown=True,
)

agent.print_response(
    "Tell me about this image and give me the latest news about it.",
    images=[
        Image(
            url="https://upload.wikimedia.org/wikipedia/commons/b/bf/Krakow_-_Kosciol_Mariacki.jpg"
        ),
    ],
    stream=True,
)
```
