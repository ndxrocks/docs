## Code

```python cookbook/11_models/cohere/tool_use.py
from kern.agent import Agent
from kern.models.cohere import Cohere
from kern.tools.hackernews import HackerNewsTools

agent = Agent(
    model=Cohere(id="command-a-03-2025"),
    tools=[HackerNewsTools()],
    markdown=True,
)

agent.print_response("Whats happening in France?")
```
