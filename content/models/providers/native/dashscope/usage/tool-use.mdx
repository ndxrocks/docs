## Code

```python cookbook/11_models/dashscope/tool_use.py
from kern.agent import Agent
from kern.models.dashscope import DashScope
from kern.tools.hackernews import HackerNewsTools

agent = Agent(
    model=DashScope(id="qwen-plus"),
    tools=[HackerNewsTools()],
    markdown=True,
)
agent.print_response("What's happening in AI today?", stream=True)
```
