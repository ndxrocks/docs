## Code

```python cookbook/11_models/dashscope/image_agent.py
from kern.agent import Agent
from kern.media import Image
from kern.models.dashscope import DashScope
from kern.tools.hackernews import HackerNewsTools

agent = Agent(
    model=DashScope(id="qwen-vl-plus"),
    tools=[HackerNewsTools()],
    markdown=True,
)

agent.print_response(
    "Analyze this image in detail and tell me what you see. Also search for more information about the subject.",
    images=[
        Image(
            url="https://upload.wikimedia.org/wikipedia/commons/0/0c/GoldenGateBridge-001.jpg"
        )
    ],
    stream=True,
)
```
