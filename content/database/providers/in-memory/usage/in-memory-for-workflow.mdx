Example using `InMemoryDb` with workflows for multi-step processes.

## Usage

```python
from kern.agent import Agent
from kern.db.in_memory import InMemoryDb
from kern.models.openai import OpenAIResponses
from kern.team import Team
from kern.tools.hackernews import HackerNewsTools
from kern.workflow.step import Step
from kern.workflow.workflow import Workflow

# Setup in-memory database
db = InMemoryDb()

# Create agents and team
research_agent = Agent(
    name="Research Agent",
    model=OpenAIResponses(id="gpt-5.2"),
    tools=[HackerNewsTools()],
)

content_agent = Agent(
    name="Content Agent",
    model=OpenAIResponses(id="gpt-5.2"),
)

# Define workflow steps
research_step = Step(name="Research", agent=research_agent)
content_step = Step(name="Content", agent=content_agent)

# Create workflow
workflow = Workflow(
    name="Content Workflow",
    db=db,
    steps=[research_step, content_step],
)

workflow.print_response("AI trends in 2024")
```
