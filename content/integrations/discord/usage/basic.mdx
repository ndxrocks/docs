## Code

```python cookbook/13_integrations/discord/basic.py
from kern.agent import Agent
from kern.integrations.discord import DiscordClient
from kern.models.openai import OpenAIResponses

basic_agent = Agent(
    name="Basic Agent",
    model=OpenAIResponses(id="gpt-5.2"),
    add_history_to_context=True,
    num_history_runs=3,
    add_datetime_to_context=True,
)

discord_agent = DiscordClient(basic_agent)
if __name__ == "__main__":
    discord_agent.serve()
```
