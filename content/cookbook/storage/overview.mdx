Storage backends persist agent sessions, chat history, and state. Use any database that fits your infrastructure.

```python
from kern.agent import Agent
from kern.db.postgres import PostgresDb

agent = Agent(
    db=PostgresDb(db_url="postgresql://ai:ai@localhost:5532/ai"),
    add_history_to_context=True,
)

agent.print_response("Hello!")
# Chat history persists across sessions
agent.print_response("What did I just say?")
```

## Supported Databases

| Database | Import | Best For |
|----------|--------|----------|
| PostgreSQL | `from kern.db.postgres import PostgresDb` | Production, teams |
| SQLite | `from kern.db.sqlite import SqliteDb` | Local development |
| MongoDB | `from kern.db.mongodb import MongoDb` | Document stores |
| Redis | `from kern.db.redis import RedisDb` | Caching, speed |
| DynamoDB | `from kern.db.dynamodb import DynamoDb` | AWS serverless |
| Firestore | `from kern.db.firestore import FirestoreDb` | GCP serverless |
| MySQL | `from kern.db.mysql import MysqlDb` | MySQL users |
| SingleStore | `from kern.db.singlestore import SingleStoreDb` | Real-time |
| SurrealDB | `from kern.db.surrealdb import SurrealDb` | Multi-model |
| GCS | `from kern.db.gcs import GCSDb` | Cloud storage |
| JSON | `from kern.db.json import JsonDb` | Simple files |
| In-Memory | `from kern.db.memory import InMemoryDb` | Testing |

## Examples by Database

### PostgreSQL

Production-ready persistence.

```python cookbook/06_storage/postgres/postgres_for_agent.py
from kern.agent import Agent
from kern.db.postgres import PostgresDb
from kern.tools.duckduckgo import DuckDuckGoTools

db = PostgresDb(db_url="postgresql+psycopg://ai:ai@localhost:5532/ai")

agent = Agent(
    db=db,
    tools=[DuckDuckGoTools()],
    add_history_to_context=True,
)

agent.print_response("How many people live in Canada?")
agent.print_response("What is their national anthem called?")
```

### SQLite

Simple local persistence.

```python cookbook/06_storage/sqlite/sqlite_for_agent.py
from kern.agent import Agent
from kern.db.sqlite import SqliteDb

agent = Agent(
    db=SqliteDb(db_file="agent.db"),
    add_history_to_context=True,
)

agent.print_response("Remember: My favorite color is blue")
agent.print_response("What is my favorite color?")
```

### MongoDB

Document-based storage.

```python cookbook/06_storage/mongo/mongodb_for_agent.py
from kern.agent import Agent
from kern.db.mongodb import MongoDb

agent = Agent(
    db=MongoDb(
        uri="mongodb://localhost:27017",
        database="kern",
        collection="agents",
    ),
    add_history_to_context=True,
)
```

### Redis

High-speed caching.

```python cookbook/06_storage/redis/redis_for_agent.py
from kern.agent import Agent
from kern.db.redis import RedisDb

agent = Agent(
    db=RedisDb(url="redis://localhost:6379"),
    add_history_to_context=True,
)
```

### DynamoDB

AWS serverless storage.

```python cookbook/06_storage/dynamodb/dynamo_for_agent.py
from kern.agent import Agent
from kern.db.dynamodb import DynamoDb

agent = Agent(
    db=DynamoDb(
        table_name="kern-agents",
        region="us-east-1",
    ),
    add_history_to_context=True,
)
```

### Firestore

GCP serverless storage.

```python cookbook/06_storage/firestore/firestore_for_agent.py
from kern.agent import Agent
from kern.db.firestore import FirestoreDb

agent = Agent(
    db=FirestoreDb(
        project_id="your-project",
        collection="agents",
    ),
    add_history_to_context=True,
)
```

### In-Memory

For testing and development.

```python cookbook/06_storage/in_memory/in_memory_storage_for_agent.py
from kern.agent import Agent
from kern.db.memory import InMemoryDb

agent = Agent(
    db=InMemoryDb(),
    add_history_to_context=True,
)
```

## Storage for Teams and Workflows

Storage works the same way for teams and workflows.

### Team Storage

```python cookbook/06_storage/postgres/postgres_for_team.py
from kern.team import Team
from kern.db.postgres import PostgresDb

team = Team(
    agents=[...],
    db=PostgresDb(db_url="postgresql://..."),
)
```

### Workflow Storage

```python cookbook/06_storage/postgres/postgres_for_workflow.py
from kern.workflow import Workflow
from kern.db.postgres import PostgresDb

workflow = Workflow(
    db=PostgresDb(db_url="postgresql://..."),
)
```
