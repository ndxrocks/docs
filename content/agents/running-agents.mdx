Running a Kern Agent kicks off a stateful orchestration loop. Behind the scenes:

1. **Context Assembly**: The agent builds the conversation payload (system prompt, user messages, history context, database preferences, and session variables).
2. **Model Reasoning**: This packet is sent to your model.
3. **Tool Loop**: If the model decides it needs to use a tool, it calls the tool. The agent executes it, appends the result, and sends it back to the model.
4. **Final Delivery**: Once the model is done looping, the agent wraps up the execution and returns the final answer.

Let's look at how to trigger and control this execution!

---

## 🏁 Basic Execution

Trigger your agent using the synchronous `Agent.run()` method. This returns a `RunOutput` helper object:

```python run_agent.py
from kern.agent import Agent, RunOutput
from kern.models.openai import OpenAIChat
from kern.tools.hackernews import HackerNewsTools
from kern.utils.pprint import pprint_run_response

# Wire up the agent using a local Ollama model
agent = Agent(
    model=OpenAIChat(id="llama3.2:3b", base_url="http://localhost:11434/v1"),
    tools=[HackerNewsTools()],
    instructions="Give a short status report.",
    markdown=True,
)

# Fire! 🎯
response: RunOutput = agent.run("Show me trending topics on HackerNews")

# Print the response nicely formatted as markdown
pprint_run_response(response, markdown=True)
```

---

## 📦 What's inside `RunOutput`?

When you call `Agent.run()`, you get back a `RunOutput` object containing rich metadata about the run. Here are the most useful attributes:

- `content`: The text response returned by the model.
- `run_id`: A unique UUID for tracking this specific run.
- `session_id`: The ID of the session (useful for history).
- `user_id`: The ID of the user who triggered the run.
- `messages`: The complete list of messages (prompts, tool calls, and tool outputs) sent to and from the model.
- `metrics`: Token usage counts, execution durations, and tool metrics.

## 🌊 Streaming Text Response

For real-time user interfaces, you want to stream tokens as they are generated by the model. Just pass `stream=True`:

```python stream_agent.py
from typing import Iterator
from kern.agent import Agent, RunOutputEvent, RunEvent
from kern.models.openai import OpenAIChat

agent = Agent(
    model=OpenAIChat(id="llama3.2:3b", base_url="http://localhost:11434/v1"),
    instructions="You are a poet.",
)

# Stream the text chunks as they arrive 🌊
stream: Iterator[RunOutputEvent] = agent.run("Write a haiku about local LLMs", stream=True)
for chunk in stream:
    if chunk.event == RunEvent.run_content:
        print(chunk.content, end="", flush=True)
```

## 📡 Rich Event Streams

If you are building a custom UI (like a web dashboard or agent console), you might want to show the user exactly what the agent is doing in real-time (e.g. "Calling HackerNews API", "Thinking..."). 

Set `stream_events=True` to receive a stream containing all system events (tool starts, tool completions, reasoning steps, memory updates, etc.):

```python stream_events.py
from kern.agent import Agent, RunEvent
from kern.models.openai import OpenAIChat
from kern.tools.hackernews import HackerNewsTools

agent = Agent(
    model=OpenAIChat(id="llama3.2:3b", base_url="http://localhost:11434/v1"),
    tools=[HackerNewsTools()],
)

# Listen to everything happening under the hood 📡
stream = agent.run("Summarize HackerNews news", stream=True, stream_events=True)

for chunk in stream:
    if chunk.event == RunEvent.run_content:
        print(chunk.content, end="", flush=True)
    elif chunk.event == RunEvent.tool_call_started:
        print(f"\n[🛠️ Tool Started] Running: {chunk.tool.tool_name}...")
    elif chunk.event == RunEvent.tool_call_completed:
        print(f"\n[✅ Tool Done] Got output length: {len(chunk.tool.tool_output)}")
```

## 📑 Core Event Reference

Here are the system event types you can listen to in your event loops:

| Event Group | Event Type | Description |
| :--- | :--- | :--- |
| **Lifecycle** | `RunStarted` | The engine has booted up for this run. |
| | `RunCompleted` | The run finished successfully. |
| | `RunError` | An exception was raised during execution. |
| | `RunCancelled` | The execution was aborted. |
| **Output** | `RunContent` | A text chunk generated by the model. |
| | `RunContentCompleted` | Model has finished generating response text. |
| **Tools** | `ToolCallStarted` | The agent is executing a tool function. |
| | `ToolCallCompleted` | The tool function has returned its output. |
| **Reasoning** | `ReasoningStarted` | The model is performing thinking steps. |
| | `ReasoningStep` | A reasoning trace chunk has arrived. |
| | `ReasoningCompleted` | Thinking process completed. |
| **Memory** | `MemoryUpdateStarted` | Extracted facts are being updated. |
| | `MemoryUpdateCompleted` | Memory transaction saved to database. |

## 🔧 Run Context Configuration

### 👤 User & Session Association
Group runs by user and thread to maintain session memory across requests:
```python
agent.run("My name is Alice", user_id="user_42", session_id="thread_abc")
```

### 🖼️ Multimodal Inputs
Send images, audio, video, or files along with the run instruction:
```python
from kern.media import Image
agent.run("Describe this layout", images=[Image(url="https://example.com/mockup.png")])
```

### 🎯 Custom Event Types
Define and yield custom telemetry data structures from your tools:
```python
from dataclasses import dataclass
from kern.run.agent import CustomEvent

@dataclass
class JobStatusEvent(CustomEvent):
    status_msg: str

# Inside a custom tool:
# yield JobStatusEvent(status_msg="Connecting to cluster...")
```

### ⏸️ Pause, Cancel & Background Runs
- **HITL (Human-In-The-Loop)**: Pause execution for user approval. Resume with `Agent.continue_run()`. See [Human-in-the-Loop Guides](/hitl/overview).
- **Abortion**: Cancel a running loop using `Agent.cancel_run()`. See [Run Cancellation Guides](/run-cancellation/overview).
- **Async Backgrounds**: Set `background=True` to execute agents as persistent background processes. See [Background Execution Guides](/background-execution/overview).
