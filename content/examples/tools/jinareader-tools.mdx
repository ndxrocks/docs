---

Enable Kern agents to convert any URL, PDF, or HTML into high-quality, LLM-friendly Markdown in real-time with Jina Reader.

```python

from kern.agent import Agent
from kern.tools.jina import JinaReaderTools

# ---------------------------------------------------------------------------
# Create Agent
# ---------------------------------------------------------------------------

agent = Agent(tools=[JinaReaderTools()])

# ---------------------------------------------------------------------------
# Run Agent
# ---------------------------------------------------------------------------
if __name__ == "__main__":
    agent.print_response("Summarize: https://github.com/kern-ai/kern")
```

# Clone and setup repo
git clone https://github.com/kern-ai/kern.git
