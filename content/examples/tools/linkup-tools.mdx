Enable Kern agents to integrate with Linkup for specialized search engine and content provider designed for LLM workflows. It allows agents to access live web and premium data sources with minimal latency, high accuracy, deep search, token efficiency, and source quality control.

```python

from kern.agent import Agent
from kern.tools.linkup import LinkupTools

# ---------------------------------------------------------------------------
# Create Agent
# ---------------------------------------------------------------------------

agent = Agent(tools=[LinkupTools()])

# ---------------------------------------------------------------------------
# Run Agent
# ---------------------------------------------------------------------------
if __name__ == "__main__":
    agent.print_response("What's the latest news in French politics?", markdown=True)
```
